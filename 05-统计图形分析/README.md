# 05-统计图形分析

本目录结合 RAWGraphs 的字段映射与图表源码，分析信息图形案例的数据结构、统计计算与视觉编码。Terra 对照表覆盖 44 个案例，可直达 159 张基础数据表。

- [01 RAWGraphs 图形与字段映射](01-RAWGraphs图形与字段映射.md)
- [02 Terra 案例的数据结构与统计图形](02-Terra案例的数据结构与统计图形.md)
- [03 RAWGraphs 参考源码索引](03-RAWGraphs参考源码索引.md)

[01 数据逻辑](../01-信息图形数据逻辑/)用于确定信息组织类型，[02 案例](../02-信息图形类型案例/)保存分析及基础数据，[03 ISOTYPE 专项](../03-ISOTYPE信息图/)讨论图符转译方法。

新增案例时，先标明原图中实际可见的编码，再整理候选数据表。依次记录观察单位、字段类型、分组键、汇总规则、单位及视觉通道。图例或原始数据不全时，明确哪些映射待核实。引用对应的独立案例报告，新增证据改变图表适用条件时同步补充方法。

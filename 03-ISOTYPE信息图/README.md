# 03-ISOTYPE 信息图专项

ISOTYPE 是一套用图符转译信息的设计方法。这个专项研究如何从资料中选取事实、建立统一的图符规则，并让读者看懂类别、数量与关系。

| 入口 | 可以查到什么 |
|---|---|
| [00 概念与方法](00-ISOTYPE概念与方法.md) | 定义、历史背景、判断特征与适用边界 |
| [01 历史与文献](01-历史与文献/README.md) | 研究线索、人物、文献与馆藏核验 |
| [02 图符语言与视觉编码](02-图符语言与视觉编码/README.md) | 图符系统、数量换算、数据表结构与排版 |
| [03 案例研究](03-案例研究/README.md) | 证据等级、归档方式与 Terra 现有局部案例 |
| [04 设计实践](04-设计实践/README.md) | 从原始资料到成品的操作步骤和交付检查 |

新增案例时，先依据 [01 的五类数据逻辑](../01-信息图形数据逻辑/) 判主类，再选 [02 的主表现标签](../02-信息图形类型案例/README.md)。采用图符转译的部分可交叉链接到本专项。涉及具体统计图形和数值映射时，结合 [05 统计图形分析](../05-统计图形分析/README.md) 查验。

当前收录《动物能活多久？》《人口与牲畜》与《每 25 人中的大城市居民》三项历史案例，以及一项 Terra 局部应用观察。历史原作、现代应用与设计实践项目分别按证据入档。

本目录结构对照 [fengbaifan/xinxikeshihua 的 03 专项（版本 f01bfdb）](https://github.com/fengbaifan/xinxikeshihua/tree/f01bfdbd62467736b72431e609ff695e29e2c2c5/03-ISOTYPE信息图)。内容依据 Terra 现有案例与归档规范整理。

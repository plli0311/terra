# 03-ISOTYPE信息图

**本专项研究 ISOTYPE 这一基础设计方法。** ISOTYPE（国际图形文字教育系统）用简化、统一的图形符号把信息转成容易辨认和比较的视觉表达。在 Terra 中，它可以与任一适用的数据主类、表现标签同时标注。

## 怎样判断

| 可观察的特征 | 如何识别 |
|---|---|
| 图符有明确意义 | 同类对象沿用同一套符号。图例或文字说明图符代表什么。 |
| 用图符表示数量 | 在同一比较口径下，以等大的同类图符重复表示数量，用图例说明每枚代表多少。 |
| 采用一致的排列 | 对齐行列或起点，让读者先识别类别，再比较数量。 |
| 图符只作导览或装饰 | 可记录为图标辅助。仅有图标时，证据不足以判定采用了 ISOTYPE 方法。 |

## 制作与核验

1. 整理类别、原始数值及单位，每列一个字段。若有分组或时间，再单列记录。
2. 为可比的各组确定同一图符换算单位，并标注「每枚图符代表多少」。使用半枚或舍入时说明换算规则。
3. 统一同类图符的尺寸和对齐方式，再按数量重复排放。保留准确读数，方便和基础表互查。
4. 归档时先写 01 数据逻辑，再写 02 主表现标签。另加「设计方法：ISOTYPE」，标明适用区域、图符、数量单位与证据。仅局部使用时注明范围。

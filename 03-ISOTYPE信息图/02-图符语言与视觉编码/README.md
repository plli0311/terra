# 图符语言与视觉编码

## 数据怎么拆

每行一个记录、每列一个字段、每格一个值。来源相同也保留可追溯的键。

| 表 | 一行代表什么 | 建议的列 |
|---|---|---|
| 基础数据表 | 一条原始观测 | 记录 ID、类别 ID、数值、计量单位、时期、来源 ID |
| 图符字典 | 一种可重复使用的图符 | 图符 ID、语义名称、资源路径、版本、来源 ID |
| 编码映射表 | 某个图层或系列的一条映射 | 图层 ID、类别 ID、图符 ID、每枚代表量、计量单位、余数处理规则 |
| 来源表 | 一项可定位的资料 | 来源 ID、资料名称、链接、页码、权利状态 |

若有多个独立时间点、地点或类别关联，可用关联表逐条保存。原始数值和换算后的图符数量分列，避免舍入后的图符个数覆盖原值。

## 画面怎么读

| 视觉通道 | 表达任务 | 检查方式 |
|---|---|---|
| 轮廓、视角 | 识别对象类别 | 同类图符尽量采用同一轮廓和抽象层级 |
| 重复个数 | 表达有固定换算单位的数量 | 由标注值除以每枚代表量，复算重复个数 |
| 行列、基线、间距 | 对齐和分组 | 比较组从同一起点读，并留出可辨分隔 |
| 色彩 | 分类或强调 | 同类配色保持一致，颜色含义能在图例或标签里查到 |
| 标题、图例、数字 | 补充图符所需的语境 | 标明比较范围、每枚单位、取整规则及数据来源 |

定量映射为「图符当量＝原值÷每枚代表量」。例如演示值为 25、每枚代表 10，则当量是 2.5。使用两枚整图符与一枚半图符时，须说明半枚代表 5。选择舍入时，保留原值 25 并说明图符为近似读数。没有数值的图符系统仍可分析类别、分组和阅读顺序。

# ISOTYPE 案例研究

| 研究对象 | 入档所需证据 |
|---|---|
| 历史原作 | 可核查的出版或馆藏记录、作者、年代及权利状态 |
| 当代方法应用 | 可核查的图符规则、数据口径和信息转译依据 |
| 视觉借鉴 | 可定位的图符或排版证据，以及适用范围；可标注 ISOTYPE-inspired |
| 局部方法观察 | 指明具体区域、可辨标记和可验证的读法，记录归属证据缺口 |

- **01 数据主类**　地理图形，主要围绕西班牙地图定位目击地点。
- **02 主表现标签**　地标型信息图形，地图标记将地点连接到事件旁注。
- **观察范围**　左栏图符与数字是一处动物数量对比。类别靠动物图形识别，读者可按重复图符和相邻数字对照。例如牛为 2、兔为 10。
- **证据边界**　局部可看到重复图符承担数量表达。作品的制作档案与 ISOTYPE 历史归属尚无证据，继续保留为局部方法观察。

## 一件作品如何建档

记录案例来源、作者或发布者、原图或馆藏链接、版权状态、分析稿、基础数据及数据字典。分析中写明类别识别、重复单位、视觉语法、阅读动线和复算方法。02 已收录的原图和 CSV 通过链接复用。图面没有给出的数值或换算单位记为待核。

当前有一项局部观察。历史原作、完整方法应用和独立作品图像等待相应来源入档。

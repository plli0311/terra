# ISOTYPE 设计实践

## 从资料到成品

| 步骤 | 要做什么 | 留下什么 |
|---|---|---|
| 1 定题 | 写出读者要回答的一个主要问题，确定受众与媒介 | 设计任务简述 |
| 2 备表 | 核对数据来源、计量口径及缺失项；以原子字段整理 | 基础数据表、数据字典和来源记录 |
| 3 搭骨架 | 选数据主类与表现标签，设定比较组、阅读入口和动线 | 信息结构草图 |
| 4 设计图符 | 建词汇表，试读轮廓，统一视角和同类尺寸 | 图符规范、可编辑素材 |
| 5 选择编码 | 写明哪些字段对应颜色、行列或图符个数；试排密集组和极值 | 映射表、布局草案 |
| 6 绘制与试读 | 配图例、单位、来源与必要文字，请试读者解释每枚图符及读数 | 成品与试读记录 |
| 7 复核与归档 | 用基础表复算图符当量，核查图文对应、取整和授权 | 校验记录、版本与成品 |

开始真实项目后，可用独立项目目录保存分析、基础数据 CSV、图符规范、可编辑源稿及成品。把观察到的效果和设计假设分别记录。借鉴图符样式的实践可明确标注其借鉴范围。

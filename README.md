## 新增案例时同步更新

1. 先判 01 数据逻辑，再判 02 主表现标签。两项判断各给出一条图面证据。
2. 在案例报告写明图形特性、视觉编码、阅读动线和制作流程。提交基础数据 CSV 并核对可打开。
3. 同步案例索引与标签说明，把新的判型证据回写 01。统计图形或计算口径改变时更新 05。

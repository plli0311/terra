## 新增案例时同步更新

1. 按主要呈现方式归档示例图和独立报告。记录可核对的图面证据，并标明待核实的出处、单位和统计口径。
2. 更新对应类型说明中的案例索引、可复用方法和适用边界。
3. 在相关数据逻辑文档添加文本链接。案例改变现有判断时，同步修订原则，并写明案例依据。局部特征应注明所指图层或区域。

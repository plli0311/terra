# 编年型信息图形概念定义

**编年型信息图形以时间关系组织记录。** 它回答何事先发生、何事同时发生、某状态持续多久，以及不同对象在同一时期如何变化。按年排列的事件年表、具有统一尺度的区间图、按期汇总的趋势图，都可属于编年型。

## A 基本的数据逻辑

| 记录粒度 | 核心字段 | 处理原则 |
|---|---|---|
| 一条事件 | 事件 ID、发生日期、日期精度、主题、对象、来源 | 同一日期可以对应多条事件。用事件 ID 区分，另设显示顺序。 |
| 一个状态区间 | 对象 ID、状态、起点、终点、端点口径、来源 | 开放区间标明截至何日仍持续。未知终点与仍在持续分别记录。 |
| 一次观测 | 对象 ID、观测时间、指标、数值、单位 | 保留原时间粒度，汇总前确认观测口径及缺期处理。 |

原文日期与机器排序键分列。只有年份的记录保留年份精度。相对年份和约略时间须注明依据，避免用人为补齐的月日表达精确先后。

## B 统计图形与计算方式

| 阅读问题 | 图形 | 计算与约束 |
|---|---|---|
| 事件按什么顺序发生 | 顺序年表、事件点轴 | 按时间键排序，同期事件可并列或另排。等距叙事轴仅用标签提供时间间隔。 |
| 两个时期持续多久、何时重叠 | 甘特图、多轨区间轴 | 同一时间尺度下，连续时间的长度为终点减起点。按日含首尾统计时明确是否加一天。 |
| 各期记录多少、指标如何变动 | 柱形图、折线图 | 以明确的时期和对象分组，按事件 ID 去重计数或按指标定义求和、求均值。缺期与零值分开。 |

《History of Manufacturing》的两个 1764 位于不同高度，显示顺序与实际时间间隔应分别解释。《Bauhaus》的多轨年表可以对齐共同年份查阅人物、作品与校址区间。

## C 视觉编码

| 元素 | 编码与优化 |
|---|---|
| 点 | 表示时间节点。将同日事件分轨、错开标签或并列，保留真实的时间锚点。 |
| 线 | 轴线引导读序，区间线表示持续，注释引线连接说明。用线型与图例区分用途。 |
| 面 | 背景带可区分时代或主题。等比例时间轴上的区间宽度可以表达持续期。 |
| 体 | 立体插图用于补充背景时，保持大小语义一致。定量持续期用同基线的平面位置或长度呈现。 |
| 符号 | 以少量重复图标区分事件类别，将精确日期与符号邻近排布。 |
| 色彩 | 色相区分主题或轨道，亮度强调关键事件，并用标签或线型支持独立辨认。 |

## D 数据与信息架构

数据层将事件、区间和周期观测分表，用对象 ID、时间键和来源关联。版面组织为「时间范围与刻度 → 阶段或轨道 → 事件与区间 → 数值或档案说明」。区间宽度、事件位置和汇总粒度如采用不同尺度，应分别标注。

## E 视觉叙事架构

先标出起点、终点和阅读方向，再用少数转折事件建立故事线。读者可顺序追踪，也可按对象跨轨比较。Royal Station Hotel 的 U 形轴需要在底部帮助读者完成折返；Spotify 局部图可先定位日期弧带，各层是否共享尺度仍需核对完整图例。

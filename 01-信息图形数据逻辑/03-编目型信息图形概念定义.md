# 编目型信息图形概念定义

**编目型信息图形以一组可检索、可比较的条目为核心。** 每个条目重复使用一套字段。分类、标签或排序帮助读者进入名录。

## A 基本的数据逻辑

一行代表一个对象，字段可含条目 ID、名称、类型、图像、核心属性、说明和来源。类别树可独立存储，对象跨类别时用对象 ID 与类别 ID 建关联表。先定条目粒度，例如一个品牌与一个产品是两种层次的对象。统一计量单位和字段定义，用不同状态记录缺失、不适用和零。

## B 统计图形与计算方式

| 图形 | 用途 | 计算与边界 |
|---|---|---|
| 卡片网格、分组列表、图标名录 | 快速识别及查阅属性 | 可直接呈现条目。每页或每组的示例数量仅代表已展示的条目。 |
| 条形图 | 比较各分类收录数量 | 以类别分组，按对象 ID 去重。多标签统计时，一个对象可以进入多组，须说明各组计数无法直接相加为总量。 |
| 象形计数、比例条 | 显示类别规模或份额 | 设定每个符号代表的单位。比例使用分组计数除以明确的分母，核查分组是否重叠。 |

《UFO IBÉRICO》底部同时有飞行物示例和类别总数。分类标签、图标示例和汇总数字各自对应不同字段。《BLACK TEA》的茶具和品牌模块可直接作为名录查阅。

## C 视觉编码

| 元素 | 编码与优化 |
|---|---|
| 点 | 圆点或编号标出条目位置、检索标签或状态，具体含义由文字补充。 |
| 线 | 网格划分卡片，短引线绑定图注，避免跨越邻近条目。 |
| 面 | 用背景块和留白分组。卡片采用一致网格，保持名称、图标、说明的对齐。 |
| 体 | 产品立体图可帮助辨认外形。若需要比较实际大小，附尺寸或统一比例。 |
| 符号 | 统一轮廓图标帮助识别类别，计数图标须给出每枚所代表的数量。 |
| 色彩 | 用色相区分有限类别，配合文字键以支持查阅。颜色编码范围在各分组间保持一致。 |

## D 数据与信息架构

以条目表为核心，连接分类表、属性表和证据来源。版面从「范围和分组索引」进入「标准化条目」，每个条目先展示识别字段，再排可比较字段和补充说明。汇总信息和条目详情各有标题与口径。

## E 视觉叙事架构

先让读者知道名录收录什么，再按类别查找、逐项理解或跨类别对照。文字和插图采用稳定次序，降低反复查阅时的定位成本。与字母表型并存时，内容仍采用名录结构，字母负责提供主查找路线。

## 实作核验与最小数据表

**判定依据**为用同一组字段浏览不同对象。先读图例、字段和查阅路径，兼有多种关系时依据作品主要回答的问题写出主归属，证据不足可标「待核实」。

| 表的用途 | 原子字段 | Excel 教学示意 |
|---|---|---|
| 用同一组字段浏览不同对象 | 条目ID、名称、类别ID、来源 | 2 行 × 4 列。两个条目可共享类别，每条保留独立 ID。 |

排名只是条目的排序属性。计算类目数量时，明确统计全部对象、图上选出的样本还是分类匹配记录。辅助标签改变时，稳定 ID 与原始属性可继续复用。

以上行列数是教学示意，表头不计入记录行数。数据来源、精度、计算口径与缺失说明另行记录。

# 层级型信息图形概念定义

**层级型信息图形以父子关系组织对象。** 其核心问题是「这个项目属于哪一层、归入哪个上级」。组织、分类和组成结构都可使用层级表达，须分别说明父子关系的含义。

## A 基本的数据逻辑

一行代表一个节点，字段包括节点 ID、父节点 ID、名称、同层顺序、关系类型、可选度量与来源。层深可沿父链计算。单父且无循环的节点适合树结构；多父归属用独立的边表记录源节点、目标节点和关系类型。同名节点通过 ID 或完整路径区分。绘图前检查缺失上级、循环引用与跨分支重复对象。

## B 统计图形与计算方式

| 图形 | 用途 | 计算与边界 |
|---|---|---|
| 树图、缩进结构图 | 展示父子、分支和深度 | 从根节点计算深度。统计子节点数量时说明是直属子节点还是全部后代。 |
| 矩形树图 | 对比组成与相对份额 | 按叶节点权重生成面积，父级汇总为子级权重之和的前提是同单位、可相加且计数口径一致。 |
| 旭日图 | 同时展示层深和份额 | 圈层标层级，角宽按权重分配。权重可用叶节点数或明确的数值。多重归属须采用去重或分配规则。 |

包豪斯课程圆图可用于观察层级与扇区组织，图面没有可见课时刻度。若改绘成定量旭日图，应先取得课时或其他有明确定义的权重。

## C 视觉编码

| 元素 | 编码与优化 |
|---|---|
| 点 | 节点对应对象，等大节点适合结构浏览，大小有数值含义时附标尺。 |
| 线 | 实线表达直接从属，跨分支关系可用虚线并明确含义，减少交叉。 |
| 面 | 嵌套边界表达包含关系。只有定义权重后，面积或角宽才用于份额比较。 |
| 体 | 立体效果容易遮蔽分支边界。以平面轮廓保留可辨识的层级结构。 |
| 符号 | 统一符号区分根、分支或叶节点，节点名称靠近对应标记。 |
| 色彩 | 同一分支可共享色相，深浅辅助辨别层级，边界与文字同时提供归属线索。 |

## D 数据与信息架构

节点表保留实体与属性，关系表记录必要的交叉归属，权重表说明单位与统计口径。版面按「根节点 → 一级分支 → 子模块 → 叶节点与注释」展开。同层模块采用一致字段和对齐方式，跨层汇总附口径说明。

## E 视觉叙事架构

先让读者识别整体与一级分支，再沿一条父子链向下阅读，最后返回同一层横向比较。分析包豪斯时应先明确所指的是右下课程图，再看圈层与材料模块。主年表的圆弧按年份读取，课程圆图的内外圈按层级读取。

## 实作核验与最小数据表

**判定依据**为父项决定子项的上下文。先读图例、字段和查阅路径，兼有多种关系时依据作品主要回答的问题写出主归属，证据不足可标「待核实」。

| 表的用途 | 原子字段 | Excel 教学示意 |
|---|---|---|
| 父项决定子项的上下文 | 节点ID、父节点ID、名称、同层顺序 | 3 行 × 4 列。根项一条，两个子项各一条。 |

先判断是上级管理、分类包含还是整体组成，再选择树状边或嵌套面。若只改变标题字号就会改变所谓层级，证据可能仅来自排版。多父节点通过边表维护，定量汇总明确去重或分摊。

以上行列数是教学示意，表头不计入记录行数。数据来源、精度、计算口径与缺失说明另行记录。

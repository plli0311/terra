# 地理图形信息图形概念定义

**地理图形信息图形以地点、区域、路线或地貌结构组织信息。** 主要阅读任务是定位、比较空间分布，或理解地理对象的垂直构成。

## A 基本的数据逻辑

| 粒度 | 核心字段 |
|---|---|
| 点位或事件 | 地点 ID、坐标或地名、位置精度、事件 ID、日期、类别、来源 |
| 区域 | 区域编码、边界、边界版本、指标、统计期、分母 |
| 路线或流向 | 起点、终点、方向、路径、单位及流量 |
| 地貌剖面 | 剖面线、水平位置、高程或深度、结构类别、水平与垂直尺度 |

地点与事件分表，通过地点 ID 关联。同地点可有多次事件，重叠点需用明确方法展开或聚合。坐标保留坐标参考系统，地名需要地域限定。位置仅为近似时，标明精度。

## B 统计图形与计算方式

| 图形 | 适用问题 | 计算或读数规则 |
|---|---|---|
| 点位地图、比例符号地图 | 事件在哪、各地点数量多少 | 分地点按事件去重计数，比例圆以面积对应数值。示意点按地名核对位置。 |
| 分级设色地图 | 不同区域的比率或密度如何 | 先定义分子、分母和统计期，再选择等距、分位数或有业务意义的分级阈值。 |
| 线路图、流向图 | 对象沿什么路线移动、流量多大 | 线示路径，箭头示方向；若用宽度表示流量，先按起终点分组并统一单位。 |
| 地貌剖面 | 地表和地下结构如何分布 | 标清剖面方向及水平、垂直尺度。垂直夸张与示意绘制应标注。 |

《UFO IBÉRICO》的点位和引线能查到具体案例，外围统计能否与图中四条案例对应须核实。《FUJI》的定位地图和剖面分别提供平面与垂直空间信息。

## C 视觉编码

| 元素 | 编码与优化 |
|---|---|
| 点 | 标注地点或事件。使用点心或锚点明确位置，必要时用引线移开文字。 |
| 线 | 路线、边界和图注使用不同样式；流向由箭头或起终点标签说明。 |
| 面 | 区域底色编码分级时，给出阈值和缺失样式。剖面填色可标地层类别。 |
| 体 | 立体地貌用于展示结构时，要让遮挡区、垂直尺度和视角易于辨识。定量比较应保证可读的比例参照。 |
| 符号 | 形状区分对象，大小表达数量时给出图例。抽象图标应与真实位置锚点对应。 |
| 色彩 | 顺序色阶表达高低，类别色区分类型。以底图退后、主题标记清楚为原则，并为无数据区域单独设样式。 |

## D 数据与信息架构

空间层管理坐标、边界与路线，属性层管理事件或指标。用稳定地理键关联，记录边界版本与统计期。版面按「地域总览 → 点位或区域 → 案例细节 → 补充统计和来源」组织，并按需要提供尺度、方向和图例。

## E 视觉叙事架构

先定位地理范围，再进入局部对象，最后返回总图比较多个地点。剖面可由地表向地下逐层阅读。涉及地图引线时，每条线应可追溯到具体条目；涉及外围总量时，明确统计覆盖的地区和时间，避免将局部案例推及整个空间范围。

## 实作核验与最小数据表

**判定依据**为位置关系回答作品的主问题。先读图例、字段和查阅路径，兼有多种关系时依据作品主要回答的问题写出主归属，证据不足可标「待核实」。

| 表的用途 | 原子字段 | Excel 教学示意 |
|---|---|---|
| 位置关系回答作品的主问题 | 地点ID、地名、经度、纬度、位置精度 | 2 行 × 5 列。两条地点记录分别维护坐标；事件表以地点 ID 关联。 |

图标占据空间时，可保留真实地图锚点并将圆符号外移，以一对一引线回指。引线表达身份对应，路线与流量须另有数据。都市圈、行政区与城市点采用不同粒度，汇总前核对边界与统计年份。

以上行列数是教学示意，表头不计入记录行数。数据来源、精度、计算口径与缺失说明另行记录。

## Terra 逐案判定

地名、区域、站点或路线决定读者从何处进入。地图可分别承载点位、密度分级与换乘拓扑。分类时先核查地图是否在回答主要问题。

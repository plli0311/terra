# 《別宗門》剧场演出海报信息图分析报告

归类为文字型信息图，细分为剧场演出公告。演员肖像名录与场次表分别提供人员浏览和时间查询入口。设计者和原始发布链接待核实。细小的票价、地址和联系方式以清晰原图为准。

## 02 分析报告

### 数据结构

演出基本信息记录剧名、剧团与演出背景。场次按日期和开演时间逐条记录，同一天可有多场。演职人员按姓名、职责、肖像或简介组织。票务记录票种与购票渠道，场地记录地址和导览图。

### 统计图形及应用

右栏的日期列表便于顺序浏览，场次矩阵以日期和时段交叉排列，点标记表示对应场次。左侧肖像网格支持人员浏览，右下角示意地图帮助确认场地和周边位置。

### 视觉编码

| 分析角度 | 版面表现 | 对应信息与阅读作用 |
|---|---|---|
| 位置与分栏 | 剧名居中，演员在左，排期、票务和场地在右。 | 分栏提供作品识别、人员浏览和观演查询入口。 |
| 字号与字重 | 剧名最大，日期放大，票务及说明文字较小。 | 剧名用于远看识别，日期便于快速扫读，细字提供操作细节。 |
| 文字方向 | 主标题与宣传文字竖排，日期、场次及联系方式主要横排。 | 竖排建立中心视觉轴线，横排便于逐项对照日期、时段和票务。 |
| 点标记与网格 | 场次点出现在日期与时段的交叉位置。 | 点的位置对应日期和时段，点的有无表示该组合是否排有演出。 |
| 明暗与图文重复 | 黑底白字，灰阶肖像以相近尺寸重复排列，姓名贴近对应肖像。 | 高反差突出标题和日期，统一的肖像尺寸与姓名位置支持逐人查找。 |

### 信息框架

顶部交代剧团、期数和演出背景，中央展示剧名与宣传文字，左栏集中演职人员和剧团资料，右栏组织日期、场次、票务及场地。

### 叙事框架

首次浏览可从剧名进入演出背景，再认识演员。已有观演意向的读者可直接查找日期与场次，随后阅读购票和场地信息。

# 《包豪斯的校长们》沃尔特·格罗皮乌斯篇信息图分析报告

格罗皮乌斯生涯以人物为中心，外圈以生卒年和作品年份索引；中央地图和建筑案例分别揭示地点与实践。红虚线将外围作品回指到时间节点。

**第二步 · 02 主表现标签**　[03 时间轴型信息图形](../%E8%AF%B4%E6%98%8E.md)。环形时标串作品卡，地图交代空间关系。

## 视觉提炼与制作流程

**视觉编码**　环点排列年份，虚线回指项目节点，照片识别项目，地图文字定位。

**视觉叙事**　先锁定人物与阶段，再沿环看作品，回地图核对活动地点。

**制作方法**　以下步骤用于据图拆解和重绘。

1. 分生涯时间锚、作品与地名。
2. 按年排环线。
3. 用引线连接作品卡与锚点。
4. 校验 1925 年等重复年份的多个项目。

**数据入口**　[基础数据表与 CSV](#基础数据表)，共 3 张表。

## 02 分析报告

### A 基本数据逻辑

生涯时间节点、作品、地图地点、相关人物是不同实体。作品用图面年份记录，1925 的两个不同作品各为一行。

### B 统计图形及应用

环线按年份引导读序，弧长无可辨线性刻度。世界地图仅定位 UK、USA、GERMANY 等区域；灰色虚线用于叙事关联，不宜读为量化流量。

### C 视觉编码

红色线和红色年份构成时间索引，灰阶建筑与肖像为识别。照片上红描边强调轮廓。小圆头像与中心肖像大小表示叙事层级。

### D 数据与信息架构

从生涯概述到时间线骨架，设计作品卡和地点区域放在不同层。可用事件 ID、作品 ID、地点 ID 建关系。

### E 视觉叙事架构

由出生日期进入，沿环读到1919建校附近与欧洲时期，再随地图和年份查看美国阶段，最后返回作品卡比较建筑类型。

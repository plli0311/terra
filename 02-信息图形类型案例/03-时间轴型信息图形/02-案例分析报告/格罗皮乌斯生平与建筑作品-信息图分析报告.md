# 《包豪斯的校长们》沃尔特·格罗皮乌斯篇信息图分析报告

主分类为编年型信息图形，细分为环形时间轴与建筑作品年表。中心地图具有地理型特征，外围建筑卡片具有编目型特征。案例名称依据图面拟定，图源为用户上传的海报，作者与原始发布链接待核实。

## 02 分析报告

### 数据结构

| 信息组 | 可整理的字段 | 组织方式 |
|---|---|---|
| 生平事件 | 日期或年份、事件、地点 | 一个时间节点可对应多个事件，保留原有日期精度。 |
| 建筑作品 | 年份、名称、地点、照片、说明 | 每件作品独立记录，同一年可对应多件作品，例如图中的两项 1925 年作品。 |
| 活动地点 | 国家或城市、地图位置、可确认的地点联系 | 地点通过标签、点位和连线显示，例如德国、英国与美国。 |

### 统计图形及应用

环形时间轴在肖像周围集中呈现生平节点。年份标签可用于判断先后，弧长是否按实际时间间隔绘制待核对。地图及连线补充地点线索，作品卡片通过年份、照片、标题和简述支持逐项浏览。

### 视觉编码

| 分析角度 | 版面特征 | 对应信息与阅读作用 |
|---|---|---|
| 环形位置与顺序 | 日期和年份沿红色弧线排布。 | 沿弧线的位置表达时间先后。外围卡片利用四周空间排放，通过引线标明时间归属。 |
| 线型与连接 | 红色实线串起生平节点，红色虚线通向作品，地图内另有灰色虚线。 | 线型、颜色和位置共同区分时间推进、年份与作品的对应及地点联系。 |
| 字号与字重 | BAUHAUS 标题最大，外围红色年份醒目，作品名和说明依次缩小。 | 先识别主题，再按年份定位，最后阅读作品详情。 |
| 色彩与明暗 | 红色用于轴线、年份、引线和部分建筑轮廓，肖像和照片以灰阶为主。 | 红色关联时间索引与作品卡片，灰阶保留人物与建筑的形态细节。 |
| 图像与尺度 | 主角肖像最大且位于中央，关联人物以圆形小头像出现，建筑照片位于外围。 | 尺寸和位置区分主角、关联人物与作品，并以照片轮廓辅助识别建筑。 |

### 信息框架

顶部标题与人物简介交代主题。中部由人物肖像、地图和生平时间轴构成。外围作品卡片通过虚线与时间轴相连。

### 叙事框架

可从右上方 1883 年起沿右侧向下，经底部和左侧读到 1969 年，建立生平顺序。也可从任一醒目的作品年份或照片切入，沿虚线回到时间轴，再结合中心地图理解地点背景。

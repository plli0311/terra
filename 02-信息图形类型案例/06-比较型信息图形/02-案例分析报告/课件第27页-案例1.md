# 西班牙 1975 与 2014 社会指标对照信息图分析报告

从胡安·卡洛斯一世到费利佩六世，用 1975 与 2014 两个截面比较西班牙的收入、物价、人口和公共指标。

## 归类与图形特性

**第一步 · 01 数据逻辑**　[03 编目型](../../../01-%E4%BF%A1%E6%81%AF%E5%9B%BE%E5%BD%A2%E6%95%B0%E6%8D%AE%E9%80%BB%E8%BE%91/03-%E7%BC%96%E7%9B%AE%E5%9E%8B%E4%BF%A1%E6%81%AF%E5%9B%BE%E5%BD%A2%E6%A6%82%E5%BF%B5%E5%AE%9A%E4%B9%89.md)。同一年龄组或指标形成比较记录，1975 与 2014 是两次截面而非连续时间尺。

**第二步 · 02 主表现标签**　[06 比较型信息图形](../%E8%AF%B4%E6%98%8E.md)。用镜像条、两色半圆和数字卡并置年份。

## 视觉提炼与制作流程

**视觉编码**　蓝红分年，中线建立共同参照，数字标明不同单位的指标。

**视觉叙事**　先认两年背景，再看收入物价，最后扫年龄组和社会统计差异。

**制作方法**　以下步骤用于据图拆解和重绘。

1. 把同一指标对齐为两年同一行。
2. 按单位分组。
3. 以共基线绘年龄条和数字卡。
4. 校对样本基数、名义金额与实际购买力口径。

**数据入口**　[基础数据表与 CSV](#基础数据表)，共 3 张表。

## 02 分析报告

### A 基本数据逻辑

用比较年度、主题、指标、值和单位记录观测。年龄人群另存上下界；婚姻一项单列资料年。百分比和人数分行，保留两种口径。

### B 统计图形及应用

上半页的两色半圆对比人均收入与工资，具体值以文字为准。下半页使用以中轴为基准的镜像条形，组内对照不同年份。卡片式数字与等大图符补充生活指标。

### C 视觉编码

蓝色对应1975，红色对应2014；肖像把年度与两任君主联系起来。统一中线让对照同步。房屋、汽车、飞机与食品符号标记指标类别。

### D 数据与信息架构

两端先交代人、时间与概览；中央呈现收入与生活成本；下半部以同年龄组和社会指标为行做细读。

### E 视觉叙事架构

先提出两个政治年代作为时间切片，再从家庭日常开支转向人口结构及社会指标。画面把变化并列呈现，未给出因果模型。

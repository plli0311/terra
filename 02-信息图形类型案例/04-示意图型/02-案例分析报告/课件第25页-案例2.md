## 02 分析报告

### A 基本数据逻辑

一行一个图面叠层。另以配料类别建名录，白面包出现于顶部与底部，因此叠层有9行、去重配料有8类。

### B 统计图形及应用

爆炸图提供上下顺序，没有比例尺、重量或制作时程。洋葱圈、番茄片等可做图面计数，不能当成配方强制用量。

### C 视觉编码

红色轮廓、点纹和浅色负空间模拟印刷质感。各层的分离与椭圆投影提示体积。点线的右端连接特定食材，红胶囊是标签而非量值。

### D 数据与信息架构

左侧标签按层顺序，右栏标题及配料 Recipe 按对象名。数据层可使用食材ID将同一类别在多处的叠层对应。

### E 视觉叙事架构

从顶层面包自上而下读配料，或从右侧清单返回左标签。爆炸层只表示空间装配，是否应从底部逐层制作未给步骤说明。

## 图面元素分析

| 图面位置 | 元素 | 表达作用 |
| --- | --- | --- |
| 上部 | 顶面面包 | 作为三明治上盖 |
| 中央 | 洋葱圈和番茄片 | 分开画出切配层 |
| 中央 | 椒圈与奶酪片 | 以轮廓及孔洞提示形态 |
| 中央下 | 肉层 | 以红色肉块细节提示 |
| 下部 | 生菜轮廓 | 用叶脉给识别线索 |
| 下部 | 酱料线条 | 标示蛋黄酱 |
| 底部 | 底面面包及投影 | 确立图形落点 |
| 左侧 | 点线与胶囊标签 | 逐层对应食材 |
| 右侧 | 标题和 Recipe | 提供简洁去重清单 |
| 整图 | 红线、网点和奶油底 | 控制材质和图形反差 |

## 基础数据表

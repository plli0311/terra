# 核验与录入规范

| 对照项 | Terra 核验与补充 |
|---|---|
| 基础逻辑 | 五类对应。补充最小 Excel 表、判型证据和边界。 |
| 表现标签 | 已有 16 类一一对应，补入词云。现有图文配对路径保留。 |
| 基础数据 | 已为各案例提供表格及 CSV，报告内附字段释义和资料缺口。 |
| 来源与权属 | 逐案核验作者、发布方、来源版本和公开归档权限；状态未知时保留记录。 |

## 两次判断与逐图写回

1. 核对原图、作品名、作者、版本、日期及来源，标注待核项。先用「读者主要按什么关系找信息」识别 01 主归属。
2. 独立判断 02 主表现标签。看主体是在排时间轴、引导步骤、做比较、定位地图、展示剖面，还是采用其他已有呈现方式。写出对应图面证据。主表现变动时更新案例索引，课件目录保留为来源入口。
3. 提炼图形特性、视觉编码与视觉叙事。说明每种元素表达哪个字段或承担什么阅读任务。叙事写入口、转折与落点。
4. 写制作步骤。逐图交代备表、图形骨架、编码与标注、核验。能从现有数据重绘的部分给出条件，缺失的图例、单位、比例与数据明确标注。
5. 将基础数据 CSV 提交到仓库。一行一个最小对象、一列一个字段、一个单元格一个值。独立保存数值、单位及限定符，层级、时点和关系字段分列。保留转录、模拟、计算或待核状态说明。
6. 写回案例报告、标签说明与案例索引。追加有依据的判型经验至 01，统计映射和计算有变化时更新 03。合并前核对图、报告与 CSV 的链接、列数和记录数。

| 01 主归属 | 判断依据 |
|---|---|
| 编年型 | 主要靠日期、持续区间或有前后约束的阶段查阅。阶段顺序和实际时刻分开。 |
| 层级型 | 主要靠父子、包含或整体与部件关系查阅。 |
| 编目型 | 主要按条目、重复字段、分类或比较对象查阅。 |
| 字母表型 | 主要由约定的文字顺序与索引键查阅。 |
| 地理图形 | 主要依据地点、区域、路线或地貌空间关系查阅。 |

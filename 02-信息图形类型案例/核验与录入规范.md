# 核验与录入规范

| 对照项 | Terra 核验与补充 |
|---|---|
| 基础逻辑 | 五类对应。补充最小 Excel 表、判型证据和边界。 |
| 表现标签 | 已有 16 类一一对应，补入词云。现有图文配对路径保留。 |
| 基础数据 | 已为各案例提供表格及 CSV，报告内附字段释义和资料缺口。 |
| 来源与权属 | 逐案核验作者、发布方、来源版本和公开归档权限；状态未知时保留记录。 |

## 录入与回写

1. 记录案例 ID、原图或官方来源、作品名、作者、版本、日期和公开归档权限状态。
2. 据主导数据关系确定基础主归属，注明图面证据与辅助关系。另填表现标签，证据不足就记录待核实。
3. 一行一个最小对象，一列一个原子字段，单元格单值。数值与单位分开，日期原文与排序键分开。
4. 数据字典注明行列数、主键、字段类型、单位、统计范围、缺失处理及来源。区分图面转录、计算、外部引入与未知。
5. 完成 A–E，并以图面位置、元素和表达作用三列逐项核对。图面计数、源数据换算和示意量各自标注。
6. 更新标签说明与总索引。能推广的发现回写 01 并加入文本链接。

参考库的都市圈营收案例演示了主数据与辅助指标分表，也演示了如何用引线维持地理锚点与外移符号的身份对应。

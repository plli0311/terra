# 风格分析与克隆系统 1.0

**启动口令：启动风格分析和克隆系统。**

本仓库是一套给具备读图能力的大模型使用的运行文档。模型承担图像观察、核心规则提取、语义适配和视觉验收。可选的离线编译器把已经审定的双语档案和主题绑定排成四版提示词，无需安装第三方包。

## Terra 仓库联动

[逐步操作与 01–05 模块交接](Terra工作流程.md) · [仓库总目录](../README.md)。以下命令在本模块目录内运行。

## 三种用法

| 使用场景 | 一次准备 | 之后怎么说 |
|---|---|---|
| 网页直接拖入 | 上传 [SYSTEM.md](SYSTEM.md)。提取具体画风时同时上传参考图。 | “启动风格分析和克隆系统。分析这些图，建立可保存的风格档案并给我四版母版。” |
| 从仓库启动 | 在能读取这个仓库的对话里指向仓库根目录，或提供该模型可访问的仓库文件。 | “阅读 07-风格分析与克隆系统/SYSTEM.md 全文，启动风格分析和克隆系统。用我附的参考图提取风格。” |
| 已有方法记忆 | 在支持持久记忆的平台上，按 [MEMORY.md](MEMORY.md) 保存方法卡，在新会话用口令复查。需要复用某个特定画风时另存档案文件、ID 和版本。 | “启动风格分析和克隆系统，调用〔档案 ID／版本〕。这次主题是〔主题〕。” |

仅有启动口令时，模型应回复已加载的方法版本并提示发图或档案。已有图或档案和主题时，直接开始当前步骤。在另一平台使用可上传同一份 SYSTEM.md；记忆能否持久化及是否成功召回取决于该平台。

## 第一次提取与后续复用

1. **第一次建档**：“分析附件中的三张参考图。先逐图观察，再确认跨图稳定的关系。交付风格档案 JSON 和四版母版。” 保存完整档案 JSON，例如 `my-style-v1.json`，并保留参考图。
2. **换主题**：“用这个档案，主题换成雨后的建筑入口。保留画法，把人物特征移出本次任务。先给主题绑定，再给四版成品提示词。”
3. **扩展主题**：“沿用当前档案和上一任务。保留入口为第一视觉焦点，增加两名撑伞的人。检查遮挡、尺度与密度，再更新四版。”
4. **验图与修订**：“这是生成结果。对照参考和风格档案，按规则 ID 标出漂移位置，保护正确区域，只修偏差后重新输出四版。”

四版依次是中文 JSON、英文 JSON、中文简易提示词、完整自然语言提示词（默认中文，可指定英文）。分析档案是可复用资产，四个版本是同一次生成要求的四种表达。

## 本地文本复用

在本目录用 Python 3.8 或更新版本运行。以下是合成教学样例，样例中的画法由文字假设给定。样例文件互相配套；SYSTEM.md 内另附一组独立的最小档案和任务。

```sh
python compile_prompts.py examples/profile.json
python compile_prompts.py examples/profile.json examples/portrait.json
python compile_prompts.py examples/profile.json examples/teapot.json
python compile_prompts.py examples/profile.json examples/station.json --natural-language en
python -m unittest -v test_system
```

第一条输出仍带 `{{role}}` 的四版母版。其余命令输出填实的实例。所有结果写到标准输出；输入文件只读。参见 [茶器四版样例](examples/茶器四版样例.md)。另见 [线描风格档案](examples/profile.json)、[人物任务](examples/portrait.json)、[茶器任务](examples/teapot.json)、[建筑任务](examples/station.json)。建筑任务关闭单点暗红这一条件，仍保留外粗内细的线条和焦点密度。

编译器检查双语字段、规则 ID、档案版本、槽位、必填条件、依赖、显式排斥和逐字保护项。每次以相同版本档案和任务调用时，输出文本可确定性重建。双语含义是否一致、一个新主题是否适合这些规则以及生成图是否保持画风，按 SYSTEM.md 的人工／多模态审查程序核对。仓库没有绑定任何图像服务、模型帐号或持久记忆接口。

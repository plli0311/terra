## 2. 判断作品类别

这是民俗节庆插画海报。画面主任务是呈现端午的龙舟活动与节日环境，文字承担题名及简短介绍。构图靠屋檐、人物、纸面空白组织，建筑未用来定位地点，人物也未被作为统计图符。

## 3. 核对数据逻辑与规格

五类信息图逻辑、统计图形、CSV 字段和量化编码在本案中不适用。底款中的节日日期与简短介绍属于文字内容。网点的密度与大小承担明暗、材质和形体消隐，图上无将点与数量对应的图例。沿用 3:4 画幅和低调落款作为这次迁移的设计选择。

## 4. 十三项观察

右上最大的玫红绿山墙最先入眼。屋檐沿斜线递向左下，将视线引到横向龙舟，最后看到水纹和底部落款。顶部宽色带给画面留出开场，建筑与活动人群之间也有纸白过渡。

| 模块 | R1 可见证据 | 作用与换主题时的边界 |
| --- | --- | --- |
| A1 风格本体 · S01 | 装饰密集的屋檐、平涂龙舟小人和裸露纸底共存。 | 民俗题材可以换。环境层负责色彩和纹样，活动层负责叙事，纸面支撑疏密对比。 |
| B1 色彩 · S02 | 屋檐与墙饰用浓玫红、鲜绿。云带偏淡薄荷和蜜桃，黑色集中在人物轮廓与底款。 | 扩大色块时仍保留浓色集中、轻色分散、暗色少量的分配。 |
| B2 光线 · S03 | 全图明亮，深色主要见于檐下与人物，地面没有明显硬投影。 | 用留纸和色阶表达明暗。画面不足以反推出确切光源。 |
| B3 空间构图 · S04 | 屋檐群左低右高，舟身在下部几乎水平，底部整片纸色。 | 以阶梯斜线表现远近，横向窄带承载活动。可替换环境和前景物件。 |
| B4 尺度 · S05 | 右上山墙很大，龙舟队员分散在细长船体内。 | 人物小于环境，但近看仍要能区分执桨、站立和持旗。 |
| C1 绘画语言 · S06 | 屋檐靠分色与细线建形，墙上有瓣形、菱格和网点，人物用简化剪影。 | 将装饰限定在结构分区内。人物靠身体方向与肢体姿态说明动作。 |
| C2 边缘 · S07 | 屋顶彩边明确，部分墙体与柱脚逐渐破边，网点稀疏后接回暖白。 | 保持轮廓的上实下虚。柱脚渐隐要和纸底自然接合。 |
| C3 完成度 · S08 | 屋脊、龙头、桨和旗鼓细节较多，地面与天空只有短水纹或浅色带。 | 将局部精度留给环境识别和活动动作，让远处有简化空间。 |
| C4 材质纹理 · S09 | 暖白纸面可见纤维状纹理，浓色色面有颗粒，部分墙面是规则网点。 | 纸纹提供底材观感，微颗粒附着色形，规则点组织局部色阶。只能据图描述视觉效果。 |
| D1 主体设计 · S10 | 成排队员靠前倾姿势与倾斜的桨重复方向，旗鼓补充活动识别。 | 换主题时保留重复动作及其可读方向，重做道具与相互关系。 |
| E1 信息密度 · S11 | 中部有高密度屋檐和墙饰，顶部低对比色带，下部留出大片无字纸面。 | 密度集中到必要的环境特征与动作，保留中段穿插和底端留白。 |
| E2 视觉锚点 · S12 | 山墙先进入视线，龙舟为次焦点，底部左对齐小字面积很小。 | 环境与活动先于文案。需要题名时用小字落在清楚纸面。 |
| E3 视觉张力 · S13 | 大屋檐与小龙舟、斜向建筑与横向活动、彩色高密区与暖白空区形成对照。 | 三组对照共同建立轻盈的节庆气氛。色彩与尺度需要一起核验。 |

## 5. 提炼规则与反事实检查

核心是暖白留纸、局部浓玫红鲜绿、斜向环境与横向动作、上缘清楚而下缘渐隐。若把网点均匀盖整页，纸白与浓色区之间的层次会消失。若把人物群放大到与屋檐同等视觉重量，环境和活动的双级焦点会变成两个竞争场景。新样图用于一次换题材检查，这些判断仍限于作品级。

短落款为可切换条件。具体题材、屋檐形态和纹样可替换。五位参与者、三只纸鸢、3:4 与两行文案为本次任务锁定项。

## 8. 编译与制作

[task.json](task.json)将主题填入角色槽位。四版实例依次为中文 JSON、英文 JSON、中文简易提示词和完整自然语言版，均见[四版提示词](四版提示词.md)。中文版与英文版的规则 ID、字段、顺序和优先级一致。母版及实例均已用 Terra 编译器复核。

制作顺序为先立暖白画幅与斜向亭群，再画布檐与栏板分区，然后加入分区网点和渐隐边缘，最后放置小人、三只风筝和左下落款。用 OpenAI 图像生成出图，模型版本、种子、参考权重未返回。[首稿实际提示词](首稿实际提示词.txt)与[修订实际提示词](修订实际提示词.txt)分别对应[首稿](draft-01.png)和[修订稿](preview-02.png)。

## 9. 样图验收

首稿的右高左低展亭、纸纹网点和留白成立。样图一中人物行列过小，三只风筝与手部的连接偏弱。修订将人物适度放大并加强线迹，保留主构图与既有两行落款。

| 项目 | 修订稿检查 |
| --- | --- |
| 风格 | 上实下虚、局部网点和彩色集中成立。右上展亭的玫红面积比参考图更突出，纸面仍保持大块安静区。 |
| 内容 | 能辨认五个人物和三只空中的纸鸢。三位牵线者的手部连接更明显，亭檐遮挡处仍难逐条追踪。 |
| 锁定项 | 人数、风筝数、竖幅和英文落款可核。中文末字的笔形与指定的简体「鸢」略有出入，尚未完成标准字复核。 |
| 图文结构 | 环境为首焦点，活动在下部承接，双语小字位于左下。 |
| 技术交付 | 两稿均为 1086 × 1448 PNG，3:4。 |
| 系列一致性 | 当前只验证了纸鸢主题，跨题材和不同画幅待检验。 |

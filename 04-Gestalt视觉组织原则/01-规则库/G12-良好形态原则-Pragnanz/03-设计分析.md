# 良好形态原则 · 设计分析

| 分析角度 | 观察内容 |
|---|---|
| 图面与任务 | 先建立主结构，再在次级层级安排细节供按需查阅。 |
| 知觉线索 | 它概括整体组织的倾向，具体分组仍取决于可用线索和画面条件。 |
| 潜在误读 | 删掉单位、来源或真实例外会损失信息，即使画面更整齐。 |
| 核验设计 | 保留同一数据和说明，改变主次层级，测试读者能否先说出主结论再定位细节。 |
